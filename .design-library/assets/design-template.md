## 토큰과 의미

이 문서는 이 패키지의 사용 규칙 문서다. Google DESIGN.md 형식으로 내보낸 결과가 아니며, 수치와 참조 관계의 정본은 tokens.json이다.

작성 필요: tokens.json의 원시 토큰과 의미별 별칭, 사용 조건과 피할 사용. 모든 토큰의 원본 근거는 evidence/coverage.md에서 추적한다. 수치 표는 토큰에서 생성하고 독립 사본을 만들지 않는다.

## 레이아웃과 밀도

작성 필요: 패널/열/정렬/크기 제약, 콘텐츠 증가와 화면 크기에 따른 변화.

## 컴포넌트와 상태

작성 필요: 구성 요소, 변형, 사용 조건, 기본/포커스/비활성 등 상태와 전환. 빈 상태/로딩/오류에서의 규칙.

## 표면과 합성

작성 필요: 표면/배경/테두리/그림자/투명 효과의 관계, 레이어 순서와 대체 표현.

## 모션과 접근성

작성 필요: 시간/이징/움직임 축소, 포커스/키보드/대비/읽기 순서.

## 플랫폼과 구현

작성 필요: 원본과 대상 플랫폼의 차이, 선택한 스택의 이유와 실행 방법.

## 분석과 디자인 결정

작성 필요: 실제 사용한 브라우저/선택적 REA 방법, 공식 자료, observed/measured/inferred/proposed의 구분. 원본에 없는 접근성 개선은 proposed로 남긴다. Taste나 prototype을 사용했다면 선택 이유와 제외 규칙을 적는다.

## 재사용 검증과 차이

작성 필요: 다른 중립 콘텐츠의 새 화면에 토큰을 연결한 방법, 원본 대표 컴포넌트 대비, 좁은/넓은 화면과 상태/키보드 검증, 의도적 변경과 미검증 범위. 실제 근거는 reference.json과 evidence/coverage.md에서 연결한다.
